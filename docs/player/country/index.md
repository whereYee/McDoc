# 国战服帮助文档

## 一、宣战规则

### 1.1 宣战条件与流程
- **正当理由要求**：宣战需提供具体理由（如资源争端、领土侵犯、违反外交协议等）
- **公示期规定**：审核通过后进入一定时间公示期，期间双方可进行外交谈判避免战争
- **战争成本**：发起方需缴纳10000金币作为战争保证金，若无故宣战或违反规则将没收保证金

### 1.2 禁止宣战情形
- 新手国家（创建未满7天）不可被宣战
- 处于休战期的国家（战败后30天内）不可被宣战
- 双方国家在线人数差超过30%时，不可发起宣战

## 二、战斗规则

### 2.2 允许与禁止行为
✅ **允许行为**：
- 使用服务器提供的武器装备和技能
- 建造防御工事与陷阱

❌ **禁止行为**：
- 使用任何第三方作弊软件或服务器漏洞
- 攻击非战场区域的和平玩家
- 利用地形BUG躲避战斗（如卡入地下、墙壁）

### 2.3 胜负判定
- **胜利条件**：摧毁对方国家核心水晶（位于首都中心建筑内）
- **失败惩罚**：战败国首都区域50%建筑随机损毁，国库资源的60%赔偿给胜利方
- **平局处理**：3天内双方均未摧毁对方水晶，则判定为平局

## 三、战败处理机制

### 3.1 投降选项
- **接受条件投降**：可与战胜国协商不超过3项合理要求（如资源赔偿、领土割让、联盟从属等）
- **无条件投降**：选择全体国民禁止上线7天，国家进入保护状态
- **流亡选项**：解散国家，所有成员变为无国籍状态，保留个人财产

### 3.2 战后秩序
- 战胜国不可对战败国进行二次攻击（休战期30天）
- 腐竹将核查战胜国提出的条件是否合理

## 五、外交机制详解

### 5.1 联合国大会系统
- **召开频率**：每月第一个周六15:00举行，所有国家领袖自动获得参会资格
- **议题范围**：国际规则修订、资源分配方案、战争仲裁、新国家准入等
- **投票规则**：每个国家拥有1票，重要议题需2/3以上赞成票通过
- **决议执行**：通过的决议由服务器自动强制执行，违反者将面临国际制裁

### 5.2 外交关系类型
| 关系类型 | 效果 | 建立条件 |
|----------|------|----------|
| 和平条约 | 互相开放贸易市场，共享部分资源点 | 双方领袖签署，缴纳5000金币保证金 |
| 军事同盟 | 可共同参战，共享军事科技 | 需联合国大会备案，至少3个国家见证 |
| 贸易联盟 | 关税减免50%，共享经济数据 | 至少2个国家发起，成员国上限8个 |
| 敌对状态 | 自动开启边境PVP，禁止贸易 | 无需条件，随时可单方面宣布 |

## 六、国战战略指南

### 6.1 经典战术流派
- **闪电战**：集中精锐部队快速突破边境，直捣对方水晶（适合高机动性国家）
- **持久战**：依托防御工事消耗敌方资源，同时派小股部队骚扰敌后补给线
- **外交孤立**：战前通过外交手段瓦解敌方联盟，争取中立国支持

### 6.2 资源管理策略
- 战争前3天开始囤积医疗物资和高级武器
- 分配20%国民专注于资源采集，确保战时消耗
- 利用外交关系从盟国获取关键战略物资

### 6.3 国家发展路线
- **军事扩张型**：优先发展武器科技和士兵训练，通过战争掠夺资源
- **经济外交型**：专注资源生产和贸易，通过经济援助影响其他国家
- **科技垄断型**：投入资源研发稀有科技，以技术优势制衡他国
