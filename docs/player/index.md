# 玩家常识

## 生存服游玩指南
* 责任管理 岂几-
生存服以提供原汁原味的我的世界生存体验为宗旨。当我的世界官方发布新版本后，服务器会在第一时间进行版本更新，玩家们不用等待太久，就能尽早体验到官方带来的最新内容。同时，生存服秉持纯净游玩的理念，不添加任何会干扰玩家正常游戏体验的插件，让大家能够在一个最原始、最纯粹的环境中感受生存玩法的乐趣。在生存服里，玩家需要依靠自己的双手收集资源、建造房屋、抵御怪物，体验从零开始的生存冒险。

## 插件生存服游玩指南
* 责任管理 天然呆
插件生存服是生存服的一个分支，专为喜欢丰富游戏内容的玩家打造。在这里，玩家可以体验到各种各样的插件内容，这些插件能为游戏增添更多玩法，比如独特的技能系统、趣味小游戏、便捷的管理功能等。插件生存服会在生存服更新时同步更新，保证玩家在体验最新官方内容的同时，也能及时体验到最新的插件内容。并且，插件服的插件大部分为服务器自制，经过了精心的设计和测试，拥有良好的兼容性和维护性，能有效减少游戏卡顿、冲突等问题，为玩家提供稳定的游戏环境。

## 模组生存服游玩指南
* 责任管理 天然呆
模组生存服在生存玩法的基础上，引入了大量有趣的模组。这些模组可以从不同方面对游戏进行拓展，比如添加新的生物、道具、建筑，或是改变游戏的规则和机制。玩家在模组生存服里能够开启一场与众不同的生存之旅，探索各种新奇的内容。服务器会严格筛选模组，确保其质量和稳定性，同时也会定期对模组进行更新和维护，为玩家提供持续且优质的游戏体验。

## 老生存服游玩指南
* 责任管理 DapperYakZsy
老生存服保留了游戏早期版本的特色，对于那些怀念经典玩法的玩家来说是一个绝佳的选择。在这里，玩家可以重温曾经熟悉的游戏界面、生物、物品和玩法，感受游戏最初的魅力。老生存服会维持相对稳定的版本，不会频繁更新，以保证玩家们能够在一个熟悉且稳定的环境中畅玩。同时，服务器管理团队也会持续维护，保障游戏的流畅性和稳定性。
