## 什么是 UiS？

UiS 的全称为 Ui's Server Ui (古关优的服务器) 古关优的中文简称为优，英文名为 Ui， UiS 是基于阿泽卡的服务端扩展而来的改良服务端

UiS 对原版服务端有着出色的兼容性，原因在于开发者在开发过程中没有对一条原版服务端的代码进行改动。在此基础上，UiS 为原版服务端增添了众多实用的功能。这些功能的加入，不仅极大地丰富了原版服务端的能力，还为使用原版服务端的用户带来了更优质的体验。

与此同时，UiS 的出现也为阿泽卡减轻了许多工作负担。以往阿泽卡可能需要花费大量精力去编写原版服务端的一些功能。

更为重要的是，UiS 为腐竹和插件开发者们提供了一个更加广阔且优质的选择空间和平台。在这个平台上，腐竹们能够更加轻松地管理和运营，插件开发者们也能充分发挥自己的才能，开发出更多富有创意和实用性的插件，满足不同用户的多样化需求

## 性能和说明

为了确保系统能够拥有卓越的性能表现以及高效的运行速度，我们精心规划并采用了 Node.js、Rust 与 C# 这三种各具独特优势的编程语言

1. Node.js 凭借其基于事件驱动和非阻塞 I/O 模型，在处理高并发请求时展现出非凡的能力，能够轻松应对大量用户同时访问的场景，极大地提升了系统的响应速度和吞吐量
2. Rust 语言则以其内存安全和高性能著称，通过其独特的所有权系统和零成本抽象机制，不仅有效避免了常见的内存泄漏和数据竞争问题，还能充分发挥底层硬件的性能潜力，为系统提供坚实可靠的底层支持。而
3. C# 作为一门功能强大且应用广泛的编程语言，凭借其丰富的类库和便捷的开发工具，为项目带来了高效的开发体验和稳定的运行保障，尤其在构建企业级应用方面表现出色

开发计划仍在继续，该项目仍在维护
