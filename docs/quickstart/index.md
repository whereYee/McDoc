## 如何加入审核群？

想要加入我们的游戏其实非常简单。首先，你需要前往我们的宣传网站（[点击这里](https://example.com)）点击上方的加入按钮即可。加入后，确保您有合适的游戏客户端版本。打开客户端，使用注册好的账号登录，看到最左边，点击后找到添加服务器按钮，添加服务器。如果在填写服务器信息遇到困难，你可以查看我们的 [填写指南](https://example.com/register-guide)，您需要通过我们的审核然后才可以获取到对应的服务器地址，这样做的目的是我们需要对服务器的其他成员负责
