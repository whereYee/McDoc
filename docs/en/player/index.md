# 游戏的基础操作

## 单人游戏

1. 你可以在单人游戏体验一个属于你的世界
2. 对于第一次游玩的玩家可以在这里来选择教程模式

## 多人游戏

1. 由于世界是多人的，所以世界的销毁需要等待，所有玩家退出才可以销毁，在这你可以体验 PVP
2. 同时一些活动/特殊的模式也会在这

## 设置

1. 如果你对默认的设置不满意，你可以更改，顶部图片，缩放，以及一些其他功能

## 创意工坊

对原版的内容体验完了之后，你可以尝试由玩家上传到创意工坊的其他

1. 舰船
2. 科技
3. 事件
4. 行星
5. 行星建筑

## 操作

1. B/鼠标右键可以呼出全局菜单
2. 对于 PC 端玩家，在游戏过程中，可以根据 UI 按钮提示的呼出对应的菜单 比如 数字键-1 可以呼出科技按钮
3. 点击实体或者与实体互动都可以和实体进行互动，这样会呼出实体的互动菜单
