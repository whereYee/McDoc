# 服务器规则
1.禁止在非规定时间段游玩服务器（凌晨1点-早上5点）

2.禁止违反国家宪法以及国家法律（比如骂人，引战，色情等）

3.禁止利用游戏Bug和服务器bug规则来为自己获取利益

4.禁止建造猎奇的建筑

5.严禁在现实中成立小团体，此处所指的国家定义是指在本服务器作为游玩的集体

6.禁止参政议政涉及政治敏感，违反党的方针，我们要坚持中国共产党的统治，坚持实施改革开放，坚持一国两制制度，坚持国家统一，民族和谐等

7.禁止服务器成员个人代表服务器整体，除非经过服务器成员同意

8.禁止使用虚拟货币（比特币等）或实体货币（人名币等）交换买卖本服务器资源（服务器虚拟货币等）

9.禁止干出一些违反人伦道德的事情

10.禁止贿赂服务器管理员，涉事管理将面临下职处理

11.生电内容禁止刷钻石等离谱的事情

# 封禁规则
1.封禁是违反规则的行为所做出的惩罚，包括但不限于设备封禁，IP封禁，账户封禁，限时封禁（禁止在本服务器游玩）

2.任何管理员都有权力对当事人进行封禁，封禁流程是先列出违反的规则，后面是封禁的时间，注意管理员在封禁的时候有权利

3.第一次情况验严重直接封禁，其他情况下第一次警告，第二次封禁

# 管理员职能
1.管理员义务：监督玩家，维护玩家权益，维护服务器形象，维护服务器正常允许等

2.管理员权力：拥有创造模式，群管理员，服务器后台等
